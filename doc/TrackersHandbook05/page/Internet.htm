Samples

Soundwave - http://www.volftp.vol.it/soundwave/samples.html
Only go to this site if you are prepared for some LARGE D/Ls.
Hyperreal - http://www.hyperreal.com/
Tons of samples, inc. the complete TR-808 and 909 sets. There is another site, the Drum Samples page, which is missing a lot of the 909 Snares, and the 808 Hi-Conga file is corrupt. I recommend Hyperreal.
SampleNet - http://www.samplenet.co.uk/
FTP Server - ftp.futurenet.co.uk/samplenet/
The WWW site provides all the links to the files on the FTP site, plus descriptions. However, directly accessing the FTP site, whether through a browser or an FTP program (make sure it allows D/L of multiple files and/or directories), is far faster.
